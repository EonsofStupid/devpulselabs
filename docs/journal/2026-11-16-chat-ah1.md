## Landmines
- Changing branch protection or Claude's own permission settings is blocked by
  the auto-mode classifier. The operator removed protection in bypass mode.
  Do not try to work around a denial.
- Scratchpad files disappear (`watch-merge.ps1`, `protection.json`). Keep
  anything needed in the repo or recreate it.
- Python `write_text` on Windows writes CRLF. Write bytes, or the diff turns
  into line-ending noise.
- PowerShell 5.1 splits a `git commit -m` message on its quotes. Use `-F`
  with a file.
- A `cfg(feature = "eguipilotai-devtools")` block needs the attribute on every
  statement that names a devtools-only type. The plain release build is what
  catches a missing one.
- Pilot runs: the depot must sit beside `target\debug`; stop only debug-build
  `devpulselabs` processes after a run, never the operator's release exe.
- `chat-local-histories` fails at RECENT CHATS on `main` too (96e415d). It is
  known broken, not a regression of later passes.

  no real transcript can appear in a committed shot.
