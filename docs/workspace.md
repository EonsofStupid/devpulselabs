# The workspace — devtools and laws

Senior setup (2026-07-22, operator directive: "get every devtool and
workspace setup first"). Everything here is machine-enforced; a law that
only lives in prose is not a law.

## THE gate

```
cargo green      # fmt --check → clippy -D warnings → tests → release build
                 # + exe-mtime assert (the stale-exe killer)
cargo xtask fix  # fmt + clippy --fix (the tidy loop)
cargo gate       # clippy alone (fast inner loop)
```

`cargo green` MUST pass before every commit. The release exe check exists
because a running instance masks a failed link — mtime is truth.

## Machine-enforced laws

- **Lints** (`[workspace.lints]`, every crate opted in): full clippy set as
  warnings, the gate promotes to errors; `unsafe_code`/`dbg!`/`todo!` deny.
  Fix findings PROPERLY (type aliases, context structs like
  `motion::Beat`) — an `#[allow]` needs a written reason.
- **deny.toml** (cargo-deny when installed): ffmpeg crates BANNED (ADR-009
  — ffmpeg is a subprocess), `multiple-versions = "deny"` (the second-egui
  incident, automated).
- **Build stamp**: the footer shows `git-hash · utc` (crates/app/build.rs)
  — the running app proves which code it is.
- **Generated code passes the gate too** — generators emit lint-clean
  output (shortest-round-trip f32 literals etc.), never `#[allow]` wrappers.

## Dev ergonomics

- `[profile.dev.package."*"] opt-level = 2` — deps (rav1e, wgpu, image)
  run at speed in dev; our crates keep O0 fast iteration.
- `tracing` + `RUST_LOG` in the app (`RUST_LOG=debug`); **F12** toggles
  egui's native inspection overlay in the running app.
- Harness flags: `--screenshot <png> --route <hub>/<sub> --shot-frame <n>
  --focus <template> --mood <n> --pixvix --pixvix-snap`.

## Structure law

- Tokens are authored (`crates/coldlight/tokens/*.json`) → generated by
  build.rs → consumed via the runtime registry. NOTHING visual is
  improvised in paint code; chrome dimensions come from the fluid `shell`
  group, colors from the pool, effects from motion/moods.
- Every generated/registered thing renders on a Library wall (the gallery
  gate). Registries over enumeration everywhere (hubs, templates, moods,
  status cells).
