Nothing else is built (CLAUDE.md, "One truth"). This is the only home of
an operator quote: other docs cite the R-id, and they never re-quote it.

- **Verbatim.** Each quote was copied from its source and machine-checked
  character for character against the tag `docs-history-2026-10-12` (every doc as of
  2026-10-12). Spelling, casing and typos are the operator's.
- **Sources.** `Source:` names where the quote was first recorded. Read it
  with `git show docs-history-2026-10-12:<path>`. `old-app:` means the prior app's docs
  (`D:\localdev\review-archive\devpulse labs`, read-only).
- **R-ids are permanent.** R1–R41 keep the numbers the chat program gave
  them. New requirements take the next free number at the end. An R-id is
  never reused.
- **Replaced, not hidden.** When a later ruling overrides an earlier one,
  both stay here, and the earlier one says **Superseded by R-n**.
- *Ratified wording* marks text an agent wrote that the operator approved.
  It is binding, but it is not the operator's own words.
