Coach · the app seam

Any installed app becomes teachable

Pick an installed application. The seam builds a profile — identity, transports, verb coverage, oracles — climbing the transport ladder per verb: the app's own API when a pack declares one, accessibility actions by default, injected input last, vision only as import fuel. Every verb returns an effect contract and emits a trace span. Coach points; Teacher may open and execute on the same rails.

Installed & classified

Every app lands on the tier ladder. The pill is the highest tier available — an adapter always uses the best rung per verb.

Ladder: R1 native API R2 a11y action R3 injected input R4 vision (import fuel)
Unprofiled apps synthesize a generic R2+R3 profile — degrade, never crash.
Seam laws: one vocabulary — foreign arms extend egui-pilot-ai-protocol, never a second agent surface · every mutating verb returns effect_observed + typed before/after · screenshots are import fuel, never the lesson hot path · overlay observes, never intercepts · traces are local-first (Arrow/Parquet · DataFusion, ADR-014), nothing leaves the machine · packs ship only on battery green and revalidate on attach.
