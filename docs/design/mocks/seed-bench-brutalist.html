BRUTALIST — three seeds, one shell, composable per component

The shell is rectangles across the top and bottom with the body between — the same skeleton in every seed, so what changes is purely the seed's formula. Each seed is a configured preset of the same ancestor, not a different code path. The bottom row proves the goal: a glass component living inside a brutalist container, keeping its own material while inheriting the container's tone.
