# Security policy

DevPULSE Labs is a pre-release project under active development. Security
fixes target the current `main` branch; there are no supported release
versions yet.

## Report a vulnerability privately

Use GitHub's [private vulnerability reporting form](https://github.com/EonsofStupid/devpulselabs/security/advisories/new)
to report a suspected vulnerability to the maintainer. Avoid public issues
or pull requests for vulnerability details until a fix and disclosure are
coordinated.

Include the affected commit, operating system, steps to reproduce and the
potential impact. Provide a minimal reproduction where possible, and remove
credentials, private conversations and other personal data from attachments.

The maintainer will assess the report and coordinate any fix and disclosure
through the private advisory. There is no guaranteed response schedule.

Public source visibility does not change the terms in [LICENSE](LICENSE).
